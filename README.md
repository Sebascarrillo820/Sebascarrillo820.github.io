# Hoja de vida web · Sebastian Andres Carrillo Jurado

Sitio personal responsive para presentar mi perfil, formación, habilidades y proyectos académicos.

## Páginas
- `index.html`: hoja de vida y perfil profesional.
- `proyectos.html`: proyectos académicos.
- `contacto.html`: correo y formulario que prepara un mensaje en la aplicación de correo del usuario.

## Tecnologías
- HTML5 semántico.
- CSS3, CSS Grid, `grid-template-areas`, `repeat()` y `minmax()`.
- Diseño Mobile First y media queries.

## Breakpoints
- Base, menos de 600px: una columna y navegación debajo de la cabecera.
- Desde 600px: presentación y secciones con más espacio; contacto en dos columnas.
- Desde 1024px: menú lateral y contenido principal en una cuadrícula de dos columnas.

## Cómo visualizar
Abre la carpeta en Visual Studio Code y ejecuta `index.html` con la extensión Live Server, o abre el archivo directamente en un navegador.
